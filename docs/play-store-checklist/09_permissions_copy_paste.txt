1. 문자(SMS) 검사 — 알림 접근 경로 (Google 심사·등록 담당자용)
================================================================================

[요약 — 0.4.22+]
- 본 앱은 Default SMS(기본 문자) 앱이 아닙니다.
- RECEIVE_SMS · READ_SMS(SMS 수신·읽기) 권한을 **선언·요청하지 않습니다**.
- 문자 URL 검사는 **알림 접근(Notification Listener)** 으로만 수행합니다.
- 대상: 삼성/구글 문자 앱 등, 알림에 URL·본문이 노출되는 경우.
- 사용자가 메인 화면에서 「보호 켜기」를 활성화한 경우에만 검사가 동작합니다.
- 「보호 끄기」 또는 「보호 일시 중지」 시 알림 기반 검사는 즉시 중단됩니다.

[사용하지 않는 권한]
- RECEIVE_SMS (문자 수신) — 미사용
- READ_SMS (문자 읽기) — 미사용
  ※ Play Console SMS Permissions Declaration Form 제출 불필요

[문자 검사 동작 (알림 경로)]

보호 OFF
- 알림 내용을 읽거나 검사하지 않습니다.

보호 ON
- 트리거: 삼성/구글 Messages 등 문자 앱의 **시스템 알림** 수신
- 읽는 데이터: 알림 제목·본문에서 URL 추출용 텍스트 (알림에 표시된 범위만)
- 처리: URL만 추출 → 서버에 URL만 전송하여 위험도 판정 → 위험 시 경고 표시
- 제한: 알림이 표시되지 않거나 본문이 잘린 경우 검사 누락 가능

[데이터 처리]
- 서버 전송: 추출된 URL 문자열만 전송 (알림·문자 본문 전체는 서버에 전송하지 않음)
- 단말 처리: 경고 창 미리보기·로컬 타임라인 표시에 알림 텍스트 일부를 단말 내에서만 사용
- 문자함(inbox) 접근·업로드: 하지 않음

[사용자 제어 방법]
- 메인 화면 「보호 끄기」 → 검사 즉시 중단, 백그라운드 서비스 종료
- 설정 「보호 일시 중지」 → 보호 스위치는 켠 채 검사만 일시 중단
- Android 설정 → 알림 접근 권한 철회 → 문자·메신저 알림 경로 비활성
- 앱 삭제 → 모든 접근 종료

2. 필수 권한·설정 목록 및 허용 사유 (보호 켜기 시)
================================================================================

[전제]
- 아래 4개 항목이 모두 완료되어야 메인 화면에서 「보호 켜기」가 정상 동작합니다.
- 앱은 보호 시작 전 설정 안내(설정 마법사)에서 각 항목의 목적을 설명합니다.
- 「권한이 왜 필요한지 보기」에서 상세 설명을 확인할 수 있습니다.

[필수 4종]

(1) 앱 알림 (Android 13 이상)
- Android 권한: POST_NOTIFICATIONS
- 왜 필요한가: 보호 기능 실행 중 상태 알림(포그라운드 서비스) 및, 다른 앱 위 표시 권한이 없을 때 탐지 결과를 알림으로 표시하기 위함
- 수집 데이터: 없음 (알림 표시 목적)

(2) 다른 앱 위에 표시
- Android 설정: SYSTEM_ALERT_WINDOW (다른 앱 위에 표시 허용)
- 왜 필요한가: 메신저·브라우저 사용 중 위험 링크를 탐지했을 때 화면 위에 경고 창을 띄우기 위함
- 수집 데이터: 없음 (UI 표시만)
- 미허용 시: 시스템 알림으로만 안내

(3) 알림 접근
- Android 설정: Notification Listener (알림 접근 권한)
- 왜 필요한가: 삼성/구글 문자 앱·카카오톡·텔레그램·LINE 등 알림에 포함된 URL을 읽어 검사하기 위함 (메신저·문자 앱별 별도 API 없음)
- 읽는 범위: 허용된 앱의 알림 제목·본문에서 URL 추출용 텍스트
- 서버 전송: URL만 전송. 알림·대화 본문 전체는 전송하지 않음
- SMS 수신·읽기 권한: **사용하지 않음**
- 보호 OFF 시: 알림 내용을 검사하지 않음 (OS 설정은 켜져 있을 수 있으나 앱 코드에서 즉시 중단)

(4) 접근성 (브라우저)
- Android 설정: Accessibility Service (접근성 서비스)
- 왜 필요한가: Chrome, Samsung Internet, Whale, Firefox 등 브라우저의 주소 표시 줄(주소창)만 읽어, 현재 방문 중인 URL을 검사하기 위함
- 읽는 범위: 브라우저 주소창 URL만. 웹 페이지 본문·입력 내용·비밀번호는 읽지 않음
- 서버 전송: URL만 전송
- 탐색 차단: 하지 않음 (경고만 표시)
- 보호 OFF 시: 주소창을 검사하지 않음

[권장 (필수 아님)]

(5) 배터리 최적화 제외
- Android 설정: 배터리 최적화 제외 허용
- 왜 권장하는가: 일부 기기에서 백그라운드 보호(포그라운드 서비스·알림 감시)가 끊기지 않도록 하기 위함
- 필수 여부: 아님. 설정하지 않아도 앱은 동작하나, 검사가 지연될 수 있음

[백그라운드 동작 (보호 ON 시)]
- 포그라운드 서비스가 실행되며, 알림 영역에 「URL 보호 실행 중」이 표시됩니다.
- 문자·메신저 알림·브라우저 주소 검사는 보호 ON 상태에서만 백그라운드로 동작합니다.
- 사용자가 「보호 끄기」를 선택하면 포그라운드 서비스가 종료되고 모든 검사가 중단됩니다.

[등록 담당자 전달용 한 줄]
본 앱은 Default SMS 앱이 아니며 RECEIVE_SMS/READ_SMS를 사용하지 않습니다. 사용자가 「보호 켜기」를 활성화한 경우에만 알림 접근·브라우저 주소창에서 URL을 추출해 스미싱 여부를 검사합니다. 알림·대화 본문은 서버에 올리지 않고 URL만 전송하며, 보호를 끄거나 알림 접근을 철회하면 즉시 중단됩니다.
