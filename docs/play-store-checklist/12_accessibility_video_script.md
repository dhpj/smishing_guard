# 접근성 API — Play Console 동영상 촬영 가이드

**앱:** 경남 안심링크 `0.4.19+`  
**목적:** Google Play 접근성 API 선언 — 명시적 고지·동의 화면 입증  
**권장 길이:** 1.5 ~ 3분

---

## 촬영 전 준비

1. `0.4.19` 이상 AAB/APK 설치 (접근성 고지 화면 포함)
2. **접근성 고지 동의 기록 초기화** (고지 화면을 다시 보이게)
   - 설정 → 앱 → 경남 안심링크 → **저장공간 → 데이터 삭제** 후 재실행  
   - 또는 앱 삭제 후 재설치
3. 폰 **화면 녹화** 켜기 (갤럭시: 빠른 설정 패널 「화면 녹화」)

---

## 촬영 순서 (이 순서 그대로)

| # | 동작 | 포인트 |
|---|------|--------|
| 1 | 앱 실행 | 메인 화면 |
| 2 | **「보호 켜기」** 스위치 ON | |
| 3 | 권한 설정 패널에서 **「접근성 (브라우저 주소창)」** → **설정 열기** | |
| 4 | **「접근성 서비스 사용 안내」** 팝업 표시 | **천천히 스크롤**해 4개 섹션 전문이 다 보이게 |
| 5 | **「동의하고 접근성 설정으로 이동」** 탭 | |
| 6 | Android 설정 → **경남 안심링크** 접근성 **ON** | |
| 7 | Chrome 실행 → 아무 URL 입력 | 주소창만 읽는다는 설명과 연결 |
| 8 | (선택) 위험 URL 테스트 시 **경고 오버레이** | 실제 사용 입증 |

**필수 구간:** 2 → 3 → 4(전문 스크롤) → 5 → 6

---

## 업로드

1. YouTube **비공개(Unlisted)** 업로드
2. Play Console → **앱 콘텐츠** → **접근성 API** 선언 → 동영상 URL 입력

---

## Play Console 선언 시 체크

- [ ] 앱은 **접근성 도구가 아님** (`isAccessibilityTool=false`)
- [ ] **앱 내** 명시적 고지·동의 화면 있음 (약관만으로 대체 안 됨)
- [ ] 동영상에 고지 화면 **전문** 포함 (스크롤 포함)
- [ ] 수집 데이터: **브라우저 주소창 URL만** (검사 목적)
