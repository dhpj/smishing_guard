# 접근성 API — Play Console 동영상 촬영 가이드

**앱:** 경남 안심링크 `0.4.21+`  
**목적:** Google Play 접근성 API 선언 — 명시적 고지·동의 화면 입증  
**권장 길이:** 2 ~ 4분

---

## 촬영 전 준비

1. `0.4.21` 이상 AAB/APK 설치 (확장 명시적 고지 화면 포함)
2. **고지 동의 기록 초기화** (고지 화면을 다시 보이게)
   - 설정 → 앱 → 경남 안심링크 → **저장공간 → 데이터 삭제** 후 재실행  
   - 또는 앱 삭제 후 재설치
3. 폰 **화면 녹화** 켜기 (갤럭시: 빠른 설정 패널 「화면 녹화」)

---

## 촬영 순서 (이 순서 그대로)

| # | 동작 | 포인트 |
|---|------|--------|
| 1 | 앱 실행 | 메인 화면 |
| 2 | **「보호 켜기」** 스위치 ON | |
| 3 | **「데이터 수집 및 접근성 서비스 안내」** 팝업 표시 | **천천히 스크롤** — 아래 5개 섹션 전문이 다 보이게 |
| 4 | 스크롤 구간 확인 | ① AccessibilityService API ② SMS/MMS ③ 기타 인앱 메시지 ④ 기타 서버 전송 ⑤ 이용자 선택 |
| 5 | **「동의하고 계속」** 탭 | |
| 6 | 권한 설정 패널에서 **「접근성 (브라우저 주소창)」** → **설정 열기** | (이미 동의했으면 고지 팝업 없이 설정으로 이동) |
| 7 | Android 설정 → **경남 안심링크** 접근성 **ON** | |
| 8 | Chrome 실행 → 아무 URL 입력 | 주소창만 읽는다는 설명과 연결 |
| 9 | (선택) 위험 URL 테스트 시 **경고 오버레이** | 실제 사용 입증 |

**필수 구간:** 2 → 3 → 4(전문 스크롤) → 5 → 6 → 7

---

## 업로드

1. YouTube **비공개(Unlisted)** 업로드
2. Play Console → **앱 콘텐츠** → **접근성 API** 선언 → **업데이트된** 동영상 URL 입력

---

## Play Console 선언 시 체크

- [ ] 앱은 **접근성 도구가 아님** (`isAccessibilityTool=false`)
- [ ] **앱 내** 명시적 고지·동의 화면 있음 (약관만으로 대체 안 됨)
- [ ] 동영상에 고지 화면 **전문** 포함 (5개 섹션 스크롤)
- [ ] **스토어 자세한 설명**에 AccessibilityService API 사용 섹션 포함
- [ ] 명시적 고지에 수집 데이터 유형 명시:
  - AccessibilityService API → 브라우저 주소창 URL (검사 목적)
  - **SMS 또는 MMS 메시지** → URL 추출·검사 (원문 미전송)
  - **기타 인앱 메시지** → 메신저 알림 URL 추출·검사 (대화 전체 미전송)
