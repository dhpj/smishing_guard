경남 안심링크 — Google Play 스토어 등록 문구 (복사용)
================================================================================

■ 한 줄 소개 (최대 80자)
--------------------------------------------------------------------------------
문자·메신저·브라우저 링크를 실시간 검사해 스미싱·피싱 위험을 알려주는 경남 안심링크


■ 짧은 소개 대안 (80자 이내)
--------------------------------------------------------------------------------
스미싱 URL 자동 탐지·즉시 경고. 문자·카톡·텔레그램·브라우저를 한 번에 보호합니다.


■ 자세한 설명 (전체)
--------------------------------------------------------------------------------
「경남 안심링크」는 문자, 카카오톡, 텔레그램, LINE, 웹 브라우저 등 일상 속에서 마주치는 링크를 자동으로 검사하고, 스미싱·피싱 등으로 의심될 경우 즉시 알려 주는 모바일 보안 앱입니다.

링크를 누르기 전에 한 번 더 확인할 수 있도록, 의심 URL을 발견하면 화면 위에 경고 창을 띄워 피해를 예방합니다.


▶ 왜 필요한가요?

최근 스미싱·피싱은 문자, 메신저, 단축 URL, 가짜 택배·금융 알림 등 다양한 경로로 확산되고 있습니다. 링크 하나만 잘못 눌러도 개인정보 유출·금전 피해로 이어질 수 있습니다.

경남 안심링크는 사용자가 평소 쓰는 앱을 그대로 이용하면서, 백그라운드에서 링크만 추출해 위험 여부를 검사합니다. 별도 회원가입 없이 설치 후 바로 사용할 수 있습니다.


▶ 주요 기능

① 문자 링크 검사 (알림 경로)
삼성/구글 문자 앱 등이 표시하는 알림에서 URL을 찾아 스미싱 여부를 검사합니다. SMS 수신·읽기 권한은 사용하지 않습니다. 알림에 URL·본문이 표시될 때 동작하며, 알림이 없거나 잘린 경우 검사가 누락될 수 있습니다.

② 메신저 알림 링크 검사
카카오톡, 텔레그램, LINE 등 메신저 알림에 포함된 링크를 실시간으로 분석합니다. 대화 전체는 수집·전송하지 않습니다.

③ 브라우저 주소창 실시간 검사
Chrome, Samsung Internet, Whale, Firefox 등 주요 브라우저의 주소 표시 줄만 읽어, 현재 방문 중인 페이지 URL을 검사합니다. 웹 페이지 본문·입력 내용은 읽지 않습니다.

④ 즉시 경고 알림
위험한 링크로 판단되면 다른 앱 사용 중에도 경고 창(오버레이)을 표시합니다. 어디서 온 링크인지(문자·메신저·웹 등)와 메시지 미리보기를 함께 보여 줍니다.

⑤ 탐지 이력(타임라인)
스미싱으로 의심된 링크만 단말에 기록합니다. 최대 30일·200건까지 로컬에 보관하며, 언제든 앱에서 확인·삭제할 수 있습니다.

⑥ 신뢰 도메인 설정
자주 쓰는 정상 사이트(회사 intranet, 은행, 쇼핑몰 등)를 등록해 불필요한 경고를 줄일 수 있습니다.

⑦ 야간·무음 시간 / 보호 일시 중지
원하는 시간대에는 진동·소리·경고 창을 끄거나, 1시간·오늘 하루 보호를 잠시 멈출 수 있습니다.


▶ 이런 분께 추천합니다

• 스미싱·피싱 문자·메신저 링크가 걱정되는 분
• 부모님·가족의 스마트폰 안전을 챙기고 싶은 분
• 택배·금융·공공기관 사칭 문자가 잦은 분
• 링크를 누르기 전에 한 번 더 확인하고 싶은 분
• 여러 앱을 오가며 일상적으로 링크를 많이 접하는 분


▶ 사용 방법

1. 앱을 설치하고 실행합니다.
2. 안내에 따라 알림 접근, 접근성(브라우저), 다른 앱 위 표시 등 필요한 권한을 허용합니다.
3. 메인 화면에서 「보호 켜기」를 누르면 실시간 검사가 시작됩니다.
4. 위험 링크가 탐지되면 경고 창과 함께 안내합니다.


▶ 앱 접근 권한 안내

정보통신망법 및 개인정보 보호법에 따라 서비스에 반드시 필요한 항목만 접근합니다.

• 알림 접근: 삼성/구글 문자 앱·카카오톡·텔레그램·LINE 등 알림 속 URL 검사 (SMS 수신·읽기 권한 미사용)
• 접근성(브라우저): 브라우저 주소 표시 줄 URL 검사
• 다른 앱 위에 표시: 위험 링크 경고 창 표시
• 알림(Android 13+): 보호 상태·탐지 결과 안내
• 배터리 최적화 제외(권장): 백그라운드 보호 유지

통화 내용, 연락처 목록, 금융 계좌, SMS 인증번호는 수집하지 않습니다.


▶ AccessibilityService API (접근성 서비스) 사용 안내

본 앱은 장애인용 접근성 보조 도구(IsAccessibilityTool)가 아닙니다.

스미싱·피싱 URL 탐지를 위해 Android AccessibilityService API를 사용합니다.

• 사용 API: Android AccessibilityService API
• 접근 대상: Chrome, Samsung Internet, Whale, Firefox 등 등록 브라우저의 주소 표시 줄(URL)만
• 수집 목적: 현재 방문 중인 웹 주소의 스미싱·피싱 위험도 검사
• 미수집: 웹페이지 본문, 비밀번호·입력 내용, 화면의 다른 UI 요소
• 서버 전송: 추출된 URL만 검사 API로 전송 (화면 원문 미전송)

앱 실행 후 「보호 켜기」 또는 접근성 설정 시, 앱 내 명시적 고지 화면에서 AccessibilityService API, 문자·메신저 알림(기타 인앱 메시지) 데이터 수집·이용 목적을 안내하고 이용자 동의를 받습니다. Android 설정에서 언제든지 접근성 서비스를 끌 수 있습니다.


▶ 개인정보 처리

• 서버로 전송: 단말 식별용 ANDROID_ID(최초 1회), 익명 userid, 검사 대상 URL
• 단말에서만 처리: 메시지 미리보기, 발신 앱 표시명, 탐지 이력
• 개인정보처리방침: http://dhncorp.co.kr/sub/service/privacy.php


▶ 중요 안내 (면책)

본 앱이 표시하는 「스미싱 의심」·「안전」 판정은 자동 분석 및 서버 데이터베이스에 기반한 참고용 결과입니다. 100% 정확한 탐지·차단을 보장하지 않으며, 오탐(정상 사이트 경고)과 미탐(악성 사이트 미경고)이 발생할 수 있습니다.

경고가 표시되더라도 해당 사이트가 반드시 악성임을 의미하지 않으며, 「안전」 판정도 위험이 없다는 보장이 아닙니다. 최종 접속·결제·개인정보 입력 여부는 이용자가 스스로 판단해야 합니다.

본 앱은 브라우저 이동·다운로드·결제 등을 강제로 차단하지 않으며, 전문 백신·보안 제품을 대체하지 않습니다. 자세한 내용은 앱 내 「오탐·면책 안내」를 참고하세요.
