경남 안심링크 개인정보처리방침

공식 URL: http://dhncorp.co.kr/sub/service/privacy.php

아래는 앱 개발용 초안입니다. Play Store·서비스 공개 시 위 공식 페이지를 사용하세요.

(주)대형네트웍스 · 시행일: 2026년 6월 12일

(주)대형네트웍스(이하 「회사」)은 「개인정보 보호법」 제30조에 따라 정보주체의 개인정보를 보호하고 이와 관련한 고충을 신속하고 원활하게 처리할 수 있도록 하기 위하여 다음과 같이 개인정보 처리방침을 수립·공개합니다.

1. 개인정보의 처리 목적

회사는 「경남 안심링크」 서비스 제공을 위해 다음 목적 범위에서만 개인정보를 처리합니다.

  • 스미싱·피싱 URL 위험도 판정 및 경고 제공
  • 서비스 이용자 식별(userid 발급·유지)
  • 서비스 품질 개선 및 오탐 신고 처리
  • 배너 광고 노출(광고 이미지·링크 제공)

2. 처리하는 개인정보 항목

서버로 전송되는 항목

  • 단말 식별 정보(ANDROID_ID): 최초 userid 발급 시 1회
  • userid: 서버 발급 익명 식별자
  • URL 문자열: 스미싱 판정을 위해 검사 대상 URL

단말 내에서만 처리되는 항목

  • 메시지 본문 일부: 경고 창 미리보기·로컬 타임라인 표시용
  • 발신 앱·발신자 표시명: 경고 카드 출처 표시용
  • 검사 이력: 단말 로컬 저장

회사는 통화 내용·연락처 목록·금융 계좌·SMS 인증번호를 수집하지 않습니다.

3. 개인정보의 처리 및 보유 기간

  • userid: 서비스 이용 기간 동안 보유, 앱 삭제·이용 종료 요청 시 지체 없이 파기
  • URL 검사 요청: 판정 목적 달성 후 지체 없이 파기 원칙
  • 로컬 타임라인: 위험 탐지 기록만 단말에 최대 30일·200건 보관

4. 개인정보의 제3자 제공

회사는 원칙적으로 이용자의 개인정보를 제3자에게 제공하지 않습니다. 이용자의 사전 동의 또는 법령에 따른 적법한 요청이 있는 경우에만 예외로 제공합니다.

5. 개인정보 처리 위탁

회사는 개인정보 처리 업무를 외부에 위탁하지 않으며, (주)대형네트웍스가 자체 인프라에서 URL 위험도 판정 API 운영, userid 관리, 광고 이미지 제공 업무를 수행합니다. 처리 방식이 변경되는 경우 본 방침을 통해 공개합니다.

6. 정보주체의 권리

이용자는 개인정보 열람·정정·삭제·처리 정지를 요청할 수 있습니다. dhn@dhncorp.co.kr 또는 055-713-7985 로 문의하세요.

7. 개인정보의 파기

전자적 파일은 복구·재생이 불가능한 방법으로 삭제합니다. 단말 로컬 데이터는 앱 데이터 삭제 또는 타임라인·캐시 비우기로 이용자가 직접 삭제할 수 있습니다.

8. 안전성 확보 조치

  • 개인정보 취급 인원 최소화 및 교육
  • userid 단말 보관 시 Android Keystore·암호화 저장소 사용
  • 서버 접근 통제·침입 차단 등 기술적 보호 조치
  • URL 전송 시 쿼리스트링·프래그먼트 제거

9. 앱 접근 권한과 수집 범위

SMS·알림 접근은 링크 추출·검사 목적이며 본문 전체는 서버에 전송하지 않습니다. 접근성(브라우저)은 주소창 URL만 읽습니다.

10. 만 14세 미만 아동

본 서비스는 만 14세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 고의로 수집하지 않습니다.
